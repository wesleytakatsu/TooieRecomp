# tools/oracle

Measurement oracles for TooieRecomp. They are **not** the game renderer.

- `angrylion-control/` — Mupen64Plus Pure Interpreter + Angrylion RDP Plus + CXD4 LLE (`ANGRYLION_CONTROL`).
- TooieRecomp itself stays on **RT64**.

How to fetch, build, and run: `docs/specs/BT/angrylion-control-oracle.md`.
