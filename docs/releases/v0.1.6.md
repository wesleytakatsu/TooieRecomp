# Banjo-Tooie Recompiled v0.1.6

## English

Windows x64 and PortMaster (aarch64 Linux handheld) pre-release, built from `main`.

### Changes since v0.1.5

#### New: music mods (HD music support)

- The game can now play **music packs**: a ZIP with an `audio.json` file and MP3s that replace the game's songs and
  jingles. Songs that a pack does not map keep the original music.
- Packs follow the game exactly as it plays its music: each **area variant** of a world's song (underwater, caves,
  interiors, Isle o' Hags near each world…) and each area's **tempo** (many areas play the same song slower or
  faster). Moving between areas crossfades the way the original does and the music stays on the beat.
- A full map of the **Banjo-Tooie HD soundtrack** is included as data only (`tools/audio/banjo-tooie-hd.json`): 193
  album tracks for 198 places in the game. If you own the album, `tools/build_audio_pack.py` builds the pack from your
  copy. Large packs load their music on demand, so a ~1 GB soundtrack does not sit in memory.
- Install a pack like any other mod: put the ZIP in the `mods` folder, then enable it in the **Mods** menu. Packs can
  be turned on and off from the ESC menu.
- **No music is included in this release.** Packs are distributed separately.

#### New: GPU selector, and the dedicated GPU first (Windows)

- New **GPU** option in **Settings → Graphics**, under Graphics API, on PCs with two or more GPUs: Auto or any GPU
  by name. It takes effect the next time the game starts.
- **Auto** now starts on the high-performance GPU (the dedicated one on a laptop, in the same order as Windows
  Settings → Display → Graphics) and only tries the other GPUs if every graphics API fails there.
- OpenGL also prefers the dedicated GPU now: the game asks the NVIDIA and AMD drivers for it. Before, OpenGL (and DX11
  in some cases) could run on the integrated GPU of a laptop.

#### More reliable startup (Windows)

- The renderer is tested hidden before the launcher appears, so a graphics API that fails no longer opens, closes
  and reopens a window.
- If the game closes because of the graphics driver during the first seconds after **Start Game**, the next start
  opens the launcher on the next graphics API, and **Auto** tries the APIs that failed on this PC (and on that GPU)
  last.
- When no graphics API works, the game shows one clear message, in English or Portuguese, listing DirectX 12, Vulkan,
  DirectX 11 and OpenGL with what happened to each, and how to fix it (install or update the video driver).
- Without a configured ROM, the launcher opens as usual with **Load ROM**.

#### Fixes

- **Story split screen:** Player 2 no longer loses AI, items, damage and shortcuts when the game moves Player 1 in
  memory. This was a regression in v0.1.4 and v0.1.5.

#### Build and maintenance

- Music-mod tests are now part of the required test suite on Windows and Linux.
- A maintainer tool records the game's own music per area and tempo, used to build and check music maps.
- README: link to the BT Reloaded texture pack.
- All features of v0.1.5 and earlier releases remain included.

### Known limitations

- **Music mods:** checked on Windows with the full HD pack: every area variant and a sample of songs and jingles
  played the right track on the beat. A few places keep the original music because the album has no matching
  recording (or recorded it at another tempo), such as three secondary areas, Grunty Industries underwater outside
  the basement and Cloud Cuckooland's trash can. Moving between areas in real play, the full campaign, Linux and
  handhelds were not checked; on handhelds a ~1 GB pack may be too heavy.
- **GPU selector:** Windows only, and only listed with two or more GPUs. Linux has no GPU selector and no startup
  fallback yet. Choosing a GPU from the menu and pressing Apply was not confirmed on screen.
- **Handheld:** same limits as v0.1.5: only the **MagicX XU10 with ROCKNIX** has run this build; the **R36S** and
  other firmwares are untested. Expect about **21–24 FPS**.
- **Linux x64:** packages for this version are not part of this release yet.
- The known limitations of v0.1.5 (experimental story split screen, the train race with the bird still allowing J2,
  intro-wall and ultrawide residuals) still apply.

### Validation and downloads

- All **34 required Windows host tests passed**, including the new music-mod tests (overlapping and 32-channel
  layers, area tempos, per-layer loops, on-demand loading). The vendored sources were verified.
- In game on Windows (GTX 1650 + AMD laptop): the GPU selector rendered on the chosen GPU with DX12, Vulkan and DX11,
  and Auto rendered on the NVIDIA with all four APIs; the startup fallback opened the launcher on the next API when
  DX12 failed; the full HD music pack played the expected track for every area variant and the sampled songs.

- Downloads:
  - **`BanjoTooieRecompiled-v0.1.6-Windows-x64.zip`**: extract it and run **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.6-Linux-arm64-PortMaster.zip`**: extract it into your device's ports folder
    (for example `roms/ports`), then start **Banjo-Tooie** from Ports.
  - Each file has a **`.sha256`** sidecar.
- Your own **Banjo-Tooie (USA) rev 0 ROM** is required. ROMs, music packs, texture packs, saves and personal
  configuration are not included.

## Português Brasileiro

Pré-release para Windows x64 e PortMaster (portáteis Linux aarch64), gerada a partir da `main`.

### Mudanças desde v0.1.5

#### Novo: mods de música (suporte a músicas HD)

- O jogo agora toca **pacotes de música**: um ZIP com um arquivo `audio.json` e MP3s que substituem as músicas e os
  jingles do jogo. As músicas que o pacote não mapeia continuam com a trilha original.
- Os pacotes seguem o jogo exatamente como ele toca a música: cada **variante de área** da música de um mundo (debaixo
  d'água, cavernas, interiores, Isle o' Hags perto de cada mundo…) e o **andamento** de cada área (várias áreas tocam a
  mesma música mais lenta ou mais rápida). Trocar de área faz a transição como no original, e a música não sai do tempo.
- Vem incluído, só como dados, um mapa completo da **trilha HD de Banjo-Tooie** (`tools/audio/banjo-tooie-hd.json`):
  193 faixas do álbum para 198 lugares do jogo. Quem tem o álbum monta o pacote a partir da própria cópia com
  `tools/build_audio_pack.py`. Pacotes grandes carregam a música sob demanda, então uma trilha de ~1 GB não fica inteira
  na memória.
- Instale um pacote como qualquer outro mod: coloque o ZIP na pasta `mods` e ative no menu **Mods**. Os pacotes podem
  ser ligados e desligados pelo menu ESC.
- **Nenhuma música vem neste release.** Os pacotes são distribuídos à parte.

#### Novo: seletor de GPU, e a GPU dedicada primeiro (Windows)

- Nova opção **GPU** em **Settings → Graphics**, abaixo de Graphics API, em PCs com duas GPUs ou mais: Auto ou qualquer
  GPU pelo nome. Vale a partir da próxima abertura do jogo.
- O **Auto** agora começa pela GPU de alto desempenho (a dedicada num notebook, na mesma ordem de Configurações do
  Windows → Tela → Gráficos) e só tenta as outras GPUs se todas as APIs gráficas falharem nela.
- O OpenGL também prefere a GPU dedicada agora: o jogo pede isso aos drivers NVIDIA e AMD. Antes, o OpenGL (e o DX11 em
  alguns casos) podia rodar na GPU integrada do notebook.

#### Inicialização mais confiável (Windows)

- O renderizador é testado escondido antes de o launcher aparecer, então uma API gráfica que falha não abre, fecha e
  reabre mais a janela.
- Se o jogo fechar por causa do driver de vídeo nos primeiros segundos depois de **Start Game**, a próxima abertura
  mostra o launcher na próxima API gráfica, e o **Auto** passa a tentar por último as APIs que falharam neste PC (e
  nessa GPU).
- Quando nenhuma API gráfica funciona, o jogo mostra uma só mensagem clara, em português ou inglês, listando DirectX 12,
  Vulkan, DirectX 11 e OpenGL com o que aconteceu em cada uma e como resolver (instalar ou atualizar o driver de vídeo).
- Sem ROM configurada, o launcher abre normalmente com **Load ROM**.

#### Correções

- **Splitscreen da história:** o Jogador 2 não perde mais IA, itens, dano e atalhos quando o jogo move o Jogador 1 na
  memória. Era uma regressão da v0.1.4 e da v0.1.5.

#### Build e manutenção

- Os testes dos mods de música agora fazem parte da suíte obrigatória no Windows e no Linux.
- Uma ferramenta de manutenção grava a música do próprio jogo por área e andamento, usada para montar e conferir mapas
  de música.
- README: link para o pacote de texturas BT Reloaded.
- Todos os recursos da v0.1.5 e das versões anteriores continuam incluídos.

### Limitações conhecidas

- **Mods de música:** conferidos no Windows com o pacote HD completo: cada variante de área e uma amostra de músicas e
  jingles tocaram a faixa certa, no tempo. Alguns lugares ficam com a música original porque o álbum não tem a gravação
  (ou gravou em outro andamento), como três áreas secundárias, Grunty Industries debaixo d'água fora do porão e a lata
  de lixo de Cloud Cuckooland. A troca de áreas jogando de verdade, a campanha completa, o Linux e os portáteis não
  foram conferidos; num portátil, um pacote de ~1 GB pode ser pesado demais.
- **Seletor de GPU:** só no Windows, e só aparece com duas GPUs ou mais. O Linux ainda não tem seletor de GPU nem o
  fallback de inicialização. Escolher uma GPU no menu e apertar Apply não foi confirmado na tela.
- **Portátil:** mesmos limites da v0.1.5: só o **MagicX XU10 com ROCKNIX** rodou este build; o **R36S** e outros
  firmwares não foram testados. Espere cerca de **21–24 FPS**.
- **Linux x64:** os pacotes desta versão ainda não fazem parte deste release.
- As limitações conhecidas da v0.1.5 (splitscreen experimental no modo história, corrida de trenzinho com o pássaro
  ainda permitindo J2, resíduos das paredes do intro e do ultrawide) continuam valendo.

### Validação e downloads

- Os **34 testes obrigatórios do Windows passaram**, inclusive os novos testes dos mods de música (camadas sobrepostas
  e de 32 canais, andamentos de área, loop por camada, carregamento sob demanda). As fontes vendorizadas foram
  conferidas.
- No jogo, no Windows (notebook com GTX 1650 + AMD): o seletor de GPU renderizou na GPU escolhida em DX12, Vulkan e
  DX11, e o Auto renderizou na NVIDIA nas quatro APIs; o fallback de inicialização abriu o launcher na próxima API quando
  o DX12 falhou; o pacote HD completo tocou a faixa prevista em cada variante de área e nas músicas da amostra.

- Downloads:
  - **`BanjoTooieRecompiled-v0.1.6-Windows-x64.zip`**: extraia e execute **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.6-Linux-arm64-PortMaster.zip`**: extraia na pasta de ports do aparelho
    (por exemplo `roms/ports`) e abra **Banjo-Tooie** em Ports.
  - Cada arquivo tem um **`.sha256`**.
- É necessária sua própria **ROM Banjo-Tooie (USA) rev 0**. ROMs, pacotes de música, pacotes de texturas, saves e
  configurações pessoais não estão incluídos.
