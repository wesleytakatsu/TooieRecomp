# Banjo-Tooie Recompiled v0.1.7

## English

Windows x64 and PortMaster (aarch64 Linux handheld) pre-release built from commit `@COMMIT@` on `main`.

### Changes since v0.1.6

#### New: Expanded Memory (experimental) and safer Object Distance

- New option **Settings → General → Expanded Memory (experimental)**, off by default. It gives the game a larger
  memory area (about 7.9 MB instead of the original 2.8 MB) and takes effect the next time the game starts.
- **Object Distance** 2x, 4x and Unlimited now require Expanded Memory. Choosing one of them turns Expanded Memory on
  and shows a restart notice; until you restart, the game keeps the original distance.
- This fixes **Witchyworld with Unlimited distance**: the game's memory ran out, so the level crashed or took several
  seconds to load, the transition Jiggy did not appear and an enemy had no body or collision.
- A memory guard keeps the original distance for a moment whenever free memory gets low.
- Expanded Memory departs from the original hardware layout. Turn it off in General if you notice anything unusual.

#### Story split screen

- **Object Distance always uses the original distance during story split screen.** With a longer distance the game
  closed by itself.
- The split-screen option in **Dev Mode → Experimental** now recommends turning on Expanded Memory.
- **Story split screen is still experimental and can break the game.** There is a lot left to adjust and there are
  many known bugs; it is being improved little by little. Save your game before using it.

#### Languages: every language now needs only the USA ROM

- **Français, Deutsch and Español are now included** with Português (Brasil); the game no longer asks for the
  European ROM.
- **Italiano (draft):** based on the Rulesless v0.9 Italian translation plus a supplemental translation that still
  needs editorial review. The Italian title screen and credits plaque are kept.
- **日本語 (Japanese) is now included.** Choose it in **Settings → General → Game Language** and restart the game; the
  Japanese ROM is not needed. The Japanese language file carries the original Japanese text, the Japanese fonts and
  the Japanese title logo; other Japanese graphics are not included and those textures keep the USA artwork.
- **Japanese still needs many checks and tests.** The text matches the original Japanese game character by
  character, but line breaks and menu widths have not been checked on screen, so errors are expected. Reports are
  welcome.

#### Documentation

- New **Italian** and **Japanese** READMEs; the languages section of all six READMEs was updated.
- README: link to the HD music mod download.

### Known limitations

- **Expanded Memory:** tested in game on Windows (Witchyworld with Unlimited distance, entering and leaving story
  split screen). Not run on Linux; on handhelds it was only built, not run on a device.
- **Japanese:** on-screen layout not verified; expect errors. **Italian** is a draft.
- **Story split screen:** experimental, with many known bugs (see above).
- **Linux x64:** no Linux x64 packages in this release yet.
- **Handheld:** only the **MagicX XU10 with ROCKNIX** has run PortMaster builds; this build was not run on a device.
- The other known limitations of v0.1.6 still apply.

### Validation and downloads

- All **35 required Windows host tests passed**, including the new expanded-memory tests (boot latch, distance
  gating, memory guard and the game's own heap running in the expanded area) and the language tests. The vendored
  sources were verified, and the GitHub CI passed on Windows, Linux x64 and the handheld cross build.
- In game on Windows: Witchyworld with Expanded Memory and Unlimited distance loaded normally (transition Jiggy and the
  enemy's body and collision back); entering and leaving story split screen with a long distance saved worked.
- Japanese: every character the game draws was compared, pixel by pixel, with what the original Japanese game draws:
  1,829 texts identical, 402 identical except where separate lines were joined, and 20 intentional adaptations. The
  shipped Japanese file matched its reference in all 2,255 entries.
- Both packages were built from the release tag with no modified files. @PACKAGES_EN@
- Downloads:
  - **`BanjoTooieRecompiled-v0.1.7-Windows-x64.zip`**: extract it and run **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.7-Linux-arm64-PortMaster.zip`**: extract it into your device's ports folder
    (for example `roms/ports`), then start **Banjo-Tooie** from Ports.
  - Each file has a **`.sha256`** sidecar.
- Your own **Banjo-Tooie (USA) rev 0 ROM** is required. ROMs, music packs, texture packs, saves and personal
  configuration are not included.

## Português Brasileiro

Pré-release para Windows x64 e PortMaster (portáteis Linux aarch64) gerada a partir do commit `@COMMIT@` na `main`.

### Mudanças desde v0.1.6

#### Novo: Memória expandida (experimental) e distância de objetos mais segura

- Nova opção **Settings → General → Expanded Memory (experimental)**, desligada por padrão. Ela dá ao jogo uma área de
  memória maior (cerca de 7,9 MB em vez dos 2,8 MB originais) e vale a partir da próxima vez que o jogo abrir.
- **Object Distance** em 2x, 4x e Unlimited agora exige a Memória expandida. Escolher uma delas liga a Memória expandida
  e mostra um aviso para reiniciar; até reiniciar, o jogo mantém a distância original.
- Isso corrige **Witchyworld com distância Unlimited**: a memória do jogo acabava, a fase fechava ou demorava vários
  segundos para carregar, o Jiggy da transição não aparecia e um inimigo ficava sem corpo e sem colisão.
- Uma proteção de memória mantém a distância original por um momento sempre que a memória livre fica baixa.
- A Memória expandida foge do layout original do hardware. Desligue em General se notar algo estranho.

#### Splitscreen da história

- **A distância de objetos fica sempre na original durante o splitscreen da história.** Com distância maior o jogo
  fechava sozinho.
- A opção de splitscreen em **Dev Mode → Experimental** agora recomenda ligar a Memória expandida.
- **O splitscreen da história continua experimental e pode quebrar o jogo.** Ainda há muito a ajustar e já existem
  muitos bugs conhecidos; o modo vai sendo melhorado aos poucos. Salve o jogo antes de usar.

#### Idiomas: todos agora precisam só da ROM USA

- **Français, Deutsch e Español agora vêm incluídos**, junto com o Português (Brasil); o jogo não pede mais a ROM
  europeia.
- **Italiano (rascunho):** baseado na tradução italiana Rulesless v0.9 mais uma tradução complementar que ainda precisa
  de revisão editorial. A tela de título italiana e a placa de créditos foram mantidas.
- **日本語 (japonês) agora vem incluído.** Escolha em **Settings → General → Game Language** e reinicie o jogo; a ROM
  japonesa não é necessária. O arquivo do idioma japonês traz o texto japonês original, as fontes japonesas e o logo
  japonês da tela de título; outros gráficos japoneses não vêm incluídos e essas texturas ficam com a arte americana.
- **O japonês ainda precisa de muitas verificações e testes.** O texto bate caractere por caractere com o jogo japonês
  original, mas quebras de linha e largura dos menus não foram conferidas na tela, então espere erros. Relatos são
  bem-vindos.

#### Documentação

- Novos READMEs em **italiano** e **japonês**; a seção de idiomas dos seis READMEs foi atualizada.
- README: link para baixar o mod de música HD.

### Limitações conhecidas

- **Memória expandida:** testada no jogo no Windows (Witchyworld com distância Unlimited, entrando e saindo do
  splitscreen da história). Não executada no Linux; nos portáteis só foi compilada, não rodou num aparelho.
- **Japonês:** layout na tela não conferido; espere erros. O **italiano** é um rascunho.
- **Splitscreen da história:** experimental, com muitos bugs conhecidos (veja acima).
- **Linux x64:** ainda não há pacotes Linux x64 nesta versão.
- **Portátil:** só o **MagicX XU10 com ROCKNIX** rodou builds PortMaster; este build não rodou num aparelho.
- As outras limitações conhecidas da v0.1.6 continuam valendo.

### Validação e downloads

- Os **35 testes obrigatórios do Windows passaram**, inclusive os novos testes da Memória expandida (leitura no boot,

  As fontes vendorizadas foram conferidas, e a CI do GitHub passou no Windows, no Linux x64 e no build cruzado do portátil.
- No jogo, no Windows: Witchyworld com Memória expandida e distância Unlimited carregou normalmente (o Jiggy da
  transição e o corpo e a colisão do inimigo voltaram); entrar e sair do splitscreen da história com distância longa
  salva funcionou.
- Japonês: cada caractere desenhado pelo jogo foi comparado, pixel a pixel, com o que o jogo japonês original desenha:
  1.829 textos idênticos, 402 idênticos exceto onde linhas separadas foram juntadas, e 20 adaptações intencionais. O
  arquivo japonês incluído bateu com a referência nas 2.255 entradas.
- Os dois pacotes foram gerados a partir da tag, sem arquivos alterados. @PACKAGES_PT@

  - **`BanjoTooieRecompiled-v0.1.7-Linux-arm64-PortMaster.zip`**: extraia na pasta de ports do aparelho
    (por exemplo `roms/ports`) e abra **Banjo-Tooie** em Ports.
  - Cada arquivo tem um **`.sha256`**.
