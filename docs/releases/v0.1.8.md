# Banjo-Tooie Recompiled v0.1.8

## English

Windows x64 and PortMaster (aarch64 Linux handheld) pre-release built from commit `a6fc70c87eb8c8451a324f565659862641d171fc` on `main`.

### Changes since v0.1.7

#### Japanese is now included

- **日本語 (Japanese) now ships with the game.** Like every other language, it needs only your USA ROM: choose it in
  **Settings → General → Game Language** and restart the game. The Japanese ROM is no longer needed.
- The Japanese language file carries the original Japanese text, the Japanese fonts and the Japanese title logo.
  Other Japanese graphics are not included; those textures keep the USA artwork.
- **Japanese still needs many checks and tests.** The text matches the original Japanese game character by
  character, but line breaks and menu widths have not been checked on screen, so errors are expected. Reports are
  welcome.
- READMEs in all six languages were updated.

Everything from v0.1.7 is included (Expanded Memory, Object Distance fixes, bundled European languages, the Italian
draft, the experimental story split screen with its warning).

### Known limitations

- **Japanese:** on-screen layout not verified; expect errors.
- **Story split screen:** experimental, can break the game, many known bugs; save before using it.
- **Linux x64:** no Linux x64 packages in this release yet.
- **Handheld:** only the **MagicX XU10 with ROCKNIX** has run PortMaster builds; this build was not run on a device.
- The other known limitations of v0.1.7 still apply.

### Validation and downloads

- All **35 required Windows host tests passed**; the language generator tests passed and the shipped Japanese file
  matched its reference in all 2,255 entries. The vendored sources were verified.
- Japanese text was compared, pixel by pixel, with what the original Japanese game draws (see v0.1.7).
- Both packages were built from the release tag with no modified files and include `assets/languages/ja.tlpb`. The
  Windows ZIP passed the content, licence mapping, manifest and SHA-256 audits (118 files); the PortMaster package was
  cross-built for aarch64 (121 files, glibc 2.35).

- Downloads:
  - **`BanjoTooieRecompiled-v0.1.8-Windows-x64.zip`**: extract it and run **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.8-Linux-arm64-PortMaster.zip`**: extract it into your device's ports folder
    (for example `roms/ports`), then start **Banjo-Tooie** from Ports.
  - Each file has a **`.sha256`** sidecar.
- Your own **Banjo-Tooie (USA) rev 0 ROM** is required. ROMs, music packs, texture packs, saves and personal
  configuration are not included.

## Português Brasileiro

Pré-release para Windows x64 e PortMaster (portáteis Linux aarch64) gerada a partir do commit `a6fc70c87eb8c8451a324f565659862641d171fc` na `main`.

### Mudanças desde v0.1.7

#### O japonês agora vem incluído

- **日本語 (japonês) agora vem com o jogo.** Como todos os outros idiomas, precisa só da sua ROM USA: escolha em
  **Settings → General → Game Language** e reinicie o jogo. A ROM japonesa não é mais necessária.
- O arquivo do idioma japonês traz o texto japonês original, as fontes japonesas e o logo japonês da tela de título.
  Outros gráficos japoneses não vêm incluídos; essas texturas ficam com a arte americana.
- **O japonês ainda precisa de muitas verificações e testes.** O texto bate caractere por caractere com o jogo japonês
  original, mas quebras de linha e largura dos menus não foram conferidas na tela, então espere erros. Relatos são
  bem-vindos.
- Os READMEs nos seis idiomas foram atualizados.

Tudo da v0.1.7 continua incluído (Memória expandida, correções da distância de objetos, idiomas europeus embutidos,
italiano em rascunho, splitscreen da história experimental com o aviso).

### Limitações conhecidas

- **Japonês:** layout na tela não conferido; espere erros.
- **Splitscreen da história:** experimental, pode quebrar o jogo, muitos bugs conhecidos; salve antes de usar.
- **Linux x64:** ainda não há pacotes Linux x64 nesta versão.
- **Portátil:** só o **MagicX XU10 com ROCKNIX** rodou builds PortMaster; este build não rodou num aparelho.
- As outras limitações conhecidas da v0.1.7 continuam valendo.

### Validação e downloads

- Os **35 testes obrigatórios do Windows passaram**; os testes do gerador de idiomas passaram e o arquivo japonês
  incluído bateu com a referência nas 2.255 entradas. As fontes vendorizadas foram conferidas.
- O texto japonês foi comparado, pixel a pixel, com o que o jogo japonês original desenha (veja a v0.1.7).
- Os dois pacotes foram gerados a partir da tag, sem arquivos alterados, e incluem `assets/languages/ja.tlpb`. O ZIP
  Windows passou nas auditorias de conteúdo, mapeamento de licenças, manifesto e SHA-256 (118 arquivos); o pacote
  PortMaster foi compilado para aarch64 (121 arquivos, glibc 2.35).

- Downloads:
  - **`BanjoTooieRecompiled-v0.1.8-Windows-x64.zip`**: extraia e execute **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.8-Linux-arm64-PortMaster.zip`**: extraia na pasta de ports do aparelho
    (por exemplo `roms/ports`) e abra **Banjo-Tooie** em Ports.
  - Cada arquivo tem um **`.sha256`**.
- É necessária sua própria **ROM Banjo-Tooie (USA) rev 0**. ROMs, pacotes de música, pacotes de texturas, saves e
  configurações pessoais não estão incluídos.
