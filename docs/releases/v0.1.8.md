# Banjo-Tooie Recompiled v0.1.8

## English

Windows x64 and PortMaster (aarch64 Linux handheld) pre-release built from the `v0.1.8` tag on `main`.

### Changes since v0.1.7

#### Fixes

- **The game no longer closes by itself on some map changes.** When the game unloaded code for the previous area, a
  range could reach into memory that belonged to another part of the game, and the recompiled runtime then stopped the
  game. This happened now and then. The range is now limited correctly, and the runtime
  keeps going instead of quitting if it ever meets that case again.
- **Widescreen: walls and scenery no longer vanish at the sides of the title screen** and other letterboxed views in
  16:9. These views use a different picture shape from normal gameplay, and the side culling was not widened enough
  for them. Normal gameplay views were already right and are unchanged.
- **60/120 FPS: fewer jumping torch fires in Mayahem Temple.** Fires that look identical could swap places between
  frames, so for a single frame a fire was drawn halfway towards another torch. This is now much rarer, but not fully
  gone.

#### New: Distant Detail (experimental)

- New option **Settings → Graphics → Distant Detail**, off by default. Models far from the camera keep their close-up
  level of detail instead of switching to the simpler distant version. It does not change how far things are drawn.

#### New: Texture Streaming (experimental)

- New option **Settings → Graphics → Texture Streaming**, off by default (Minimum to Maximum). For **HD texture packs**:
  each texture is loaded at the size its distance needs, keeping video memory use well below what the pack would
  otherwise take. Only with **Direct3D 12 or Vulkan**. Without a texture pack it changes nothing.
  Textures whose size is not a power of two (for example 1252) load whole, so no dark lines appear along their edges.

### Known limitations

- **Texture packs are not included.** On **OpenGL and Direct3D 11**, textures from texture packs can still appear black
  (known issue from earlier versions); use Direct3D 12 or Vulkan with texture packs.
- **Texture Streaming** has been measured, but its look has not yet been checked across the game. **Distant Detail**
  was checked on Banjo; other maps and objects were not checked one by one.
- **Mayahem Temple torches:** an occasional glitch can remain at 60/120 FPS.
- **Linux:** none of these changes were run on Linux; no Linux x64 packages in this release.
- **Handheld:** only the **MagicX XU10 with ROCKNIX** has run PortMaster builds; this build was not run on a device.
- The other known limitations of v0.1.7 still apply.

### Validation and downloads

- All **37 required Windows host tests passed**, plus 15 extra tests, including the new tests for Distant Detail,
  Texture Streaming, the widescreen side planes and the torch re-pairing. The vendored sources were verified (59
  patches).
- In game on Windows, before this release: many map changes with no crash after the map-change fix; title screen
  walls present in 16:9; no dark lines with HD packs and Texture Streaming High; Banjo detailed far away with Distant Detail; fewer torch glitches in Mayahem Temple.

- Downloads:
  - **`BanjoTooieRecompiled-v0.1.8-Windows-x64.zip`**: extract it and run **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.8-Linux-arm64-PortMaster.zip`**: extract it into your device's ports folder
    (for example `roms/ports`), then start **Banjo-Tooie** from Ports.
  - Each file has a **`.sha256`** sidecar.
- Your own **Banjo-Tooie (USA) rev 0 ROM** is required. ROMs, music packs, texture packs, saves and personal
  configuration are not included.

## Português Brasileiro

Pré-release para Windows x64 e PortMaster (portáteis Linux aarch64) gerada a partir da tag `v0.1.8` na `main`.

### Mudanças desde v0.1.7

#### Correções

- **O jogo não fecha mais sozinho em algumas trocas de mapa.** Ao descarregar o código da área anterior, um intervalo
  podia alcançar memória de outra parte do jogo, e o runtime recompilado encerrava o jogo. Acontecia de vez em quando.
  O intervalo agora é limitado corretamente, e o runtime segue em frente em vez de fechar
  se encontrar esse caso de novo.
- **Widescreen: paredes e cenário não somem mais nas laterais da tela de título** e de outras vistas com faixas
  (letterbox) em 16:9. Essas vistas usam um formato de imagem diferente do jogo normal, e o corte lateral não era
  ampliado o bastante para elas. As vistas do jogo normal já estavam certas e não mudaram.
- **60/120 FPS: menos fogo de tocha pulando em Mayahem Temple.** Fogos idênticos podiam trocar de lugar entre quadros,
  e por um quadro um fogo era desenhado no meio do caminho para outra tocha. Agora é bem mais raro, mas não sumiu de vez.

#### Novo: Distant Detail (experimental)

- Nova opção **Settings → Graphics → Distant Detail**, desligada por padrão. Modelos longe da câmera mantêm o nível de
  detalhe de perto em vez de trocar pela versão simplificada. Não muda a distância de desenho.

#### Novo: Texture Streaming (experimental)

- Nova opção **Settings → Graphics → Texture Streaming**, desligada por padrão (Minimum a Maximum). Para **pacotes de
  textura HD**: cada textura é carregada no tamanho que a distância pede, usando bem menos memória de vídeo do que o
  pacote ocuparia. Só com **Direct3D 12 ou Vulkan**. Sem pacote de textura não muda nada.
  Texturas com tamanho que não é potência de dois (por exemplo 1252) carregam inteiras, sem linhas escuras nas bordas.

### Limitações conhecidas

- **Pacotes de textura não estão incluídos.** Em **OpenGL e Direct3D 11**, texturas de pacotes ainda podem aparecer
  pretas (problema conhecido de versões anteriores); com pacotes de textura use Direct3D 12 ou Vulkan.
- **Texture Streaming** foi medido, mas a aparência ainda não foi conferida pelo jogo todo. **Distant Detail** foi
  conferido no Banjo; outros mapas e objetos não foram conferidos um a um.
- **Tochas de Mayahem Temple:** uma falha ocasional pode continuar em 60/120 FPS.
- **Linux:** nenhuma destas mudanças foi executada no Linux; sem pacotes Linux x64 nesta release.
- **Portáteis:** só o **MagicX XU10 com ROCKNIX** já rodou builds PortMaster; esta build não foi executada num aparelho.
- As demais limitações conhecidas da v0.1.7 continuam valendo.

### Validação e downloads

- Os **37 testes obrigatórios no Windows passaram**, mais 15 extras, incluindo os testes novos de Distant Detail,
  Texture Streaming, planos laterais do widescreen e repareamento das tochas. As fontes vendorizadas foram verificadas
  (59 patches).
- No jogo, no Windows, antes desta release: muitas trocas de mapa sem crash depois da correção; paredes da tela de
  título presentes em 16:9; sem linhas escuras com pacotes HD e Texture Streaming em High; Banjo detalhado de longe com Distant Detail; menos falhas nas tochas de Mayahem Temple.

- Downloads:
  - **`BanjoTooieRecompiled-v0.1.8-Windows-x64.zip`**: extraia e execute **`TooieRecompiled.exe`**.
  - **`BanjoTooieRecompiled-v0.1.8-Linux-arm64-PortMaster.zip`**: extraia na pasta de ports do aparelho
    (por exemplo `roms/ports`) e inicie **Banjo-Tooie** em Ports.
  - Cada arquivo tem um **`.sha256`** ao lado.
- É necessária a sua própria **ROM Banjo-Tooie (USA) rev 0**. ROMs, pacotes de música, pacotes de textura, saves e
  configurações pessoais não estão incluídos.
