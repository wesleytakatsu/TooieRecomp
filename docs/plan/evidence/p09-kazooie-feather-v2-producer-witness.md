## Scale legality (`PROVEN` static)

Tooie bone local slots are first-class TRS. `func_800AE820` is the
AnimMtxList builder:

```text
func_800AE160 / func_800AE1E8
  a2 = AnimMtxList + 0x50
  func_800AE820
    func_800AE8A8   // quat compose + scale multiply into slot 0x40
    func_800AEAA0   // quat+scale -> 3x3
    func_800AEBA8   // rest+anim translation into 4x4
```

`func_800AE8A8` (`PROVEN` generated C):

- skeleton bone stride `0x10` at `a1+8`; `+0xC` = boneAnimID; `+0xE` = parent index
- animation record stride `0x28` at `*a0 + boneAnimID*0x28`
  - `+0x00..+0x0C` quat
  - `+0x10/+0x14/+0x18` local scale
  - `+0x1C` translation pointer, stored at output `+0x30`
- composed scale = parent_scale * (anim scale, optionally rewritten by `func_800AF04C`)
- optional `func_800AEDA0` if `a3+8` nonzero (quat)
- optional `func_800AF04C` if `a3+9` nonzero; that path calls `func_800E0E94`
  and AE8A8 multiplies the returned `f11/f12/f13` as **scale**
  (`CORRECTED/SUPERSEDED` vs treating this consume as type-3 Euler)


## Boot crash (`PROVEN`, core 3120935, 2026-09-04T02:53-03)

`TOOIE_DIAG_SECONDARY_SWAY=1` segfaulted in intro
(`chintrochar` → `func_800AE160` → wrap AE820 → `func_800AEBA8`).
Status file stayed `REASON=INIT`. Producer CSV was never created.

Cause: the AE8A8 wrap saved `a0–a3` as `uint32_t` and wrote them back
into `ctx->r4..r7`. Recompiled `MEM_*` is
`rdram + (reg + offset - 0xFFFFFFFF80000000)`, so KSEG0 pointers must
remain sign-extended `gpr` values. Zero-extension made AEBA8 index
past the RDRAM mapping.

Fix (diagnostic only): save/restore full `gpr`; AE820 dump uses saved
copies and does not rewrite caller registers. No production fix.

Do not request a visual capture until this repaired binary is confirmed
to boot with the producer CSV.
