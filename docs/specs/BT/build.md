# BT — Build

The `Makefile` produces an ELF that matches the original ROM layout, then a
recompressed runnable ROM. The invariant is byte-exact matching.

## Key variables

| Variable | Value |
| -------- | ----- |
| `BUILD_ROOT` | `build/us` |
| `ELF` | `build/us/banjotooie_decompressed.elf` |
| `UNCOMPRESSED_ROM` | `build/us/banjotooie_decompressed.z64` |
| `ROM` | `build/us/banjotooie.z64` |
| `BASEROM` | `baserom.us.z64` |
| `DECOMPRESSED_BASEROM` | `decompressed.us.z64` |
| `LD_SCRIPT` | `banjotooie.ld` |
| `SPLAT_YAML` | `baserom.us.yaml` |

## Sources gathered

- `C_SRCS` — every `.c` under `src/`
- `S_SRCS` — `.s` under `asm/` excluding `asm/nonmatchings/`
- `HASM_SRCS` — `.s` inside `src/`
- `BIN_SRCS` — `.bin` under `assets/`, excluding `relocs.bin`
- `OVERLAYS` — list from `tools/list_overlays.py overlays.us.toml`

## Toolchain

```make
CC       := tools/ido/cc        # IDO 5.3 recompiled
AS       := mips-linux-gnu-gcc
OBJCOPY  := mips-linux-gnu-objcopy
LD       := mips-linux-gnu-ld
ASM_PROC := python3 tools/asm-processor/asm_processor.py
```

Flags:

- `CFLAGS`: `-O2 -G0 -Xcpluscomm -mips2 -woff 807` via IDO
- `CPPFLAGS`: `-I include -I lib/ultralib/include -I src -DBUILD_VERSION=VERSION_J -D_FINALROM -DF3DEX_GBI_2`
- `ASFLAGS`: `-march=vr4300 -mabi=32 -mips3 -G0 -fno-pic` (GNU as)
- `LDFLAGS`: `-nostdlib -T undefined_syms.us.txt --emit-relocs --whole-archive`

## Nonmatching C

Files containing `#pragma GLOBAL_ASM(...)` get preprocessed through
`asm-processor`:

1. `asm_processor` expands the pragma into a stub function for compile.
2. The C file is compiled with IDO.
3. `asm_processor --post-process` splices in the original assembly for that
   function.

The final object therefore contains the original hand-written assembly for
nonmatching functions and the decompiled C for matched ones — both byte-exact.

## Prelim ELF and overlay processing

```make
$(PRELIM_ELF): $(ALL_OBJS) $(PRELIM_LD_SCRIPT) ...
    $(LD) -T $(PRELIM_LD_SCRIPT) ... -o $@

$(OVERLAY_HEADER_SRCS) $(OVERLAY_TABLE_SRC) &: $(PRELIM_ELF)
    tools/overlay_processor $(PRELIM_ELF) $(BUILD_ROOT)/assets > /dev/null
```

1. `PRELIM_LD_SCRIPT` = `banjotooie.ld` with `assets/overlay*` lines stripped.
2. Link prelim ELF (overlays not yet placed).
3. `overlay_processor` reads `overlays.us.toml`, finds every segment's
   size/entrypoints/relocs in the ELF, and emits:
   - `assets/overlay_table.s`
   - `assets/overlays/<ovl>/<ovl>_header.s` per overlay
4. Final `$(ELF)` links those generated objects + `overlay_syscalls.s`.

## Final ROM

```make
$(UNCOMPRESSED_ROM): $(ELF)
	$(OBJCOPY) -O binary --gap-fill=0x00 $< $@

$(ROM): $(UNCOMPRESSED_ROM) $(ELF)
	tools/rom_compressor $(UNCOMPRESSED_ROM) $(ELF) $(ROM) $(BASEROM) $(DECOMPRESSED_BASEROM)
	tools/n64crc $@ > /dev/null
```

The compressor (`rom_compressor`) reads the original `baserom.us.z64`
compressed stream and emits the recompressed `ROM` from the decompressed ELF,
then `n64crc` recomputes the header checksum.

## `make check`

```make
check: $(ROM)
	diff build/us/banjotooie_decompressed.z64 decompressed.us.z64 && printf "OK\n"
```

## Resource: syscalls

- `overlay_syscalls.s` is generated by `tools/syscall_builder` from
  `overlays.us.toml` (see [Overlays](overlays.md)).

## Cleanup

- `make clean` — remove `build/us` artifacts but keep `.asmproc.d`, eeprom.
- `make distclean` — nukes `build/`, `asm/`, `assets/`, `decompressed` and
  tracks, plus ultralib & tools.
