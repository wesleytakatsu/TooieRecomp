# Asset Ownership and Licensing Manifest

## 1. Core Principles & Clean-Room Boundaries

TooieRecomp enforces a strict separation between open-source engine virtualization code and proprietary Nintendo / Rare game data. The repository does not host, distribute, or version proprietary ROM dumps, extracted textures, dialog scripts, audio banks, or raw level models.

```text
+---------------------------------------------------------------------------------+
|                       Clean-Room Recompilation Architecture                     |
|                                                                                 |
|  [User-Supplied ROM] (Proprietary, Private, Unlicensed)                         |
|         │                                                                       |
|         ▼                                                                       |
|  [banjo-tooie-Recomp Decompilation & ELF Generation]                            |
|         │                                                                       |
|         ▼                                                                       |
|  [N64Recomp / RSPRecomp Code Generators]                                        |
|         │                                                                       |
|         ▼                                                                       |
|  [RecompiledFuncs/*.c] (ROM-Derived C code - Private Local Use Only)            |
|         │                                                                       |
|         ├──────────────────────────┐                                            |
|         ▼                          ▼                                            |
|  [Native Source Code]      [Permissive Engine Runtimes]                         |
|  (TooieRecomp Host Logic)  (RT64 [MIT], N64ModernRuntime [MIT],                 |
|                            ultramodern [MIT], RecompFrontend [GPLv3])           |
|         │                          │                                            |
|         └──────────┬───────────────┘                                            |
|                    ▼                                                            |
|          [TooieRecompiled Executable]                                           |
|          (Binary embeds ROM-derived translated logic;                           |
|           Designated strictly as 'private-local', not for public distribution)  |
+---------------------------------------------------------------------------------+
```

### 2.1 Vendored closure (standalone repository)
Every third-party source the build needs is vendored as regular files (`lib/`, `decomp/`, `assets/`, `recompcontrollerdb.txt`, `tools/wheelhouse/`);
the per-upstream URL, pin, licence-file hashes and licence status are in `vendor/UPSTREAMS.tsv` (heuristic byte match, **not legal clearance**).
Rows that remain `UNKNOWN` / `UNVERIFIED` (RecompFrontend root, DXC prebuilt binaries, `decomp/` and `ultralib` sources, font and screenshot rights, project licence)
are owner decisions and **block any public redistribution of the source archive or a package** until resolved. Upstream names/headers/licence files are preserved;
no authorship is claimed. The `vendor/DERIVED-FILES.tsv` list marks the Tooie files that share a path with GPL-3.0 BanjoRecomp content. Prebuilt third-party binaries
are an allowlist (`vendor/BINARIES.tsv`); the private ROM, extracted assets, generated `RecompiledFuncs/` and the IDO/gcc kit are never in the repository.

## 4. Packaging and Redistribution Policy

1. **Automated Manifest Enforcement (`THIRD-PARTY-MANIFEST.tsv`):**
   - Packager runs `tools/package_manifest.sh` backed by rule table `tools/package_licenses.tsv`.
   - Every staged file is inventoried with path, sha256, size, category, origin, and license status.
   - Any staged file lacking a matching rule fails the package build immediately (`exit 1`).
   - In the candidate Linux packages (initial pre-standalone package: 105 files with 41 flagged rows; corrected standalone package: 101 regular archive files (99 at audit time), 100 in manifest), rows flagged as `UNKNOWN` or `UNVERIFIED` remain open owner decisions blocking public redistribution.
2. **Private-Local Designation:**
   - Any package produced by `tools/package_linux.sh` or `Build-Tooie.ps1` that embeds `TooieRecompiled` is named with the `-private-local` suffix (e.g. `TooieRecompiled-linux-x86_64-*-dirty-private-local.tar.gz`).
   - The package is strictly for local testing by the user who owns the prerequisite cartridge.
3. **Package Content Audit Invariant:**
   - Standalone packages are audited to ensure zero forbidden files (`.z64`, `.n64`, `.v64`, `.rom`, `.elf`, `.sav`, `.eep`, `.log`, `.json`, `baserom*`).
   - All third-party software licenses are aggregated into the package `licenses/` directory (58 license files included).
4. **Decoupling Technical Readiness from Licensing:**
   - Technical readiness (compilation, linking, test pass, launch smoke) evaluates whether the software functions correctly.
   - Licensing decisions (public distribution, legal release models, clean-room asset replacers) are strictly reserved for the project owner.
