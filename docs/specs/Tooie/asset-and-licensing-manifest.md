# Asset Ownership and Licensing Manifest

## 1. Core Principles & Clean-Room Boundaries

TooieRecomp enforces a strict separation between open-source engine virtualization code and proprietary Nintendo / Rare game data. The repository does not host, distribute, or version proprietary ROM dumps, extracted textures, dialog scripts, audio banks, or raw level models.

```text
+---------------------------------------------------------------------------------+
|                       Clean-Room Recompilation Architecture                     |
|                                                                                 |
|  [User-Supplied ROM] (Proprietary, Private, Unlicensed)                         |
|         │                                                                       |
|         ▼                                                                       |
|  [decomp/ Decompilation Sources & ELF Generation]                               |
|         │                                                                       |
|         ▼                                                                       |
|  [N64Recomp / RSPRecomp Code Generators]                                        |
|         │                                                                       |
|         ▼                                                                       |
|  [RecompiledFuncs/*.c] (ROM-Derived C code - Private Local Use Only)            |
|         │                                                                       |
|         ├──────────────────────────┐                                            |
|         ▼                          ▼                                            |
|  [Native Source Code]      [Permissive Engine Runtimes]                         |
|  (TooieRecomp Host Logic)  (RT64 [MIT], N64ModernRuntime [MIT/GPLv3],            |
|                            ultramodern [MIT], RecompFrontend)                   |
|         │                          │                                            |
|         └──────────┬───────────────┘                                            |
|                    ▼                                                            |
|          [TooieRecompiled Executable]                                           |
|          (Binary embeds ROM-derived translated logic;                           |
|           Designated strictly as 'private-local', not for public distribution)  |
|+--------------------------------------------------------------------------------+
```

### 2.1 Vendored Closure & Third-Party Auditing
- Every third-party source is vendored as regular files under `lib/`, `decomp/`, `assets/`, `recompcontrollerdb.txt`, and `tools/wheelhouse/`.
- Provenance and tracking: `vendor/UPSTREAMS.tsv`, `vendor/patches-applied/ORDER.tsv`, `vendor/BINARIES.tsv`, `vendor/EXCLUDES.txt`, and `vendor/MANIFEST.sha256`.
- Any component rows remaining `UNKNOWN` or `UNVERIFIED` block public redistribution until explicitly cleared.

## 4. Packaging and Redistribution Policy

1. **Automated Manifest Enforcement (`THIRD-PARTY-MANIFEST.tsv`)**:
   - Packager runs `tools/package_manifest.sh` backed by rule table `tools/package_licenses.tsv`.
   - Every staged file is inventoried with path, hash, size, category, origin, and license status.
   - Any staged file lacking a matching rule fails the package build immediately (`exit 1`).
2. **Private-Local Designation**:
   - Packages produced by `tools/package_linux.sh` or `Build-Tooie.ps1` that bundle `TooieRecompiled` carry the `-private-local` suffix.
   - Such packages are strictly for private local use by users providing their own legally acquired cartridge ROM.
3. **Package Content Audit Invariant**:
   - Distribution packages are validated by `tools/verify_package.py`.
   - Prohibited files: `.z64`, `.n64`, `.v64`, `.elf`, `.sav`, `.eep`, `.log`, `baserom*`, `decompressed*`.
   - Any `*.json` file at the root of the distribution package is forbidden, and configuration files (`graphics.json`, `general.json`, `sound.json`, `controls.json`) must never be bundled anywhere in the archive.
   - All third-party licenses are aggregated into the package `licenses/` directory.
