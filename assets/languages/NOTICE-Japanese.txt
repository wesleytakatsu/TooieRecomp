Japanese language data

Source: Banjo to Kazooie no Daibouken 2 (Japan) ROM.
Normalized big-endian SHA-1: 5a5172383037d171f121790959962703be1f373c.
Original Japanese text, glyph artwork and game graphics: Nintendo/Rare.

ja.tlpb is generated by tools/build_japanese_bundle.py for the verified USA executable.
It contains the original Japanese text, the original Japanese font glyph artwork (normalized to IA8)
and the original Japanese title logo model. No other Japanese graphics are included. It converts the native character codes, preserves USA event
controls, joins Japanese line fragments into the fields the USA game reads, keeps the USA credits,
and adapts a few variable-dependent messages, the demo label and a USA-only quiz menu to the USA game.
No Japanese executable code and no ROM image are included. The game still runs from the USA ROM.

The Japanese text, glyph artwork and title logo are proprietary Nintendo/Rare content and are not
covered by the project licence. This notice and the host-side conversion code do not grant rights to
the original game assets.
